# desktop-statusline

給 Claude **桌面 app** 用的狀態列，顯示在輸入框上方：

```
5h ███░░░░░░░ 34% · 2h10m 後重置 · 約 1h20m 後用完 │ 7d █░░░░░░░░░ 12% · 3d4h 後重置 │ Context ████░░░░░░ 42% / 200k │ $1.23
```

（百分比類的欄位會畫成進度條，上面用 `█░` 示意。）要顯示哪些欄位、排成幾行、什麼順序，可以用 `/desktop-statusline` 打開設定畫面，用選的來調整（見下方）。

終端機版已經有好用的 statusline 工具，所以這個 mod 預設只在桌面 app 顯示。想在終端機也顯示，可以在設定裡打開（見下方）。

## 安裝

在終端機的 Claude Code 中輸入：

```
/plugin install desktop-statusline --marketplace williamchen0606/claude-mods
```

選擇 **user** scope 安裝後，桌面 app 的 Code 分頁也會載入這個 mod。

## 顯示內容

| 欄位（設定畫面中的名稱） | 顯示 | 說明 |
| --- | --- | --- |
| 5 小時用量 | `5h ███░░░░░░░ 34%` | 5 小時用量窗口已用的百分比 |
| 5 小時重置倒數 | `2h10m 後重置` | 距離 5 小時窗口重置的時間 |
| 5 小時還能撐多久 | `約 1h20m 後用完` / `可撐到重置` | 依目前的消耗速度估算，5 小時額度會在重置前用完，還是撐得到重置 |
| 7 天用量 | `7d █░░░░░░░░░ 12%` | 7 天（每週）用量已用的百分比 |
| 7 天重置倒數 | `3d4h 後重置` | 距離 7 天窗口重置的時間 |
| Context 使用率 | `Context ████░░░░░░ 42% / 200k` | 目前對話佔 context window 的比例，以及 window 大小 |
| 花費 | `$1.23` | 這個 session 到目前為止的花費，和 `/cost` 相同。訂閱方案下是依 API 價格換算的估計值 |

同一類的欄位相鄰時用 `·` 連接（例如 `5h 34% · 2h10m 後重置`），不同類之間用 `│` 分隔。

進度條平常是綠色，用量超過 70% 變黃色，超過 90% 變紅色，百分比文字也一樣。

- 5 小時和 7 天的用量只有訂閱方案（Pro / Max）才有。使用 API key 時不會顯示這兩欄。
- 第一次收到回應之前，Context 會顯示 `–`。

### 「還能撐多久」怎麼算

1. 這個 mod 會記錄 5 小時窗口的用量變化。紀錄存在 mod 自己的 store，跨 session 共用，因為 5 小時窗口是整個帳號共用的。
2. 最近 30 分鐘內有至少 5 分鐘的紀錄時，用這段期間的消耗速度估算；紀錄不足時，改用這個窗口從開始到現在的平均速度。
3. 把估算的用完時間和重置時間比較：會先用完就顯示「約 X 後用完」，否則顯示「可撐到重置」。剛開新窗口、資料還不夠時，不會顯示這一項。

## 更新時機

- 每輪對話結束後，以及 5 小時或 7 天用量每變動 1% 時，Claude Code 會主動通知 mod 更新。
- 另外每 30 秒更新一次，讓倒數時間保持正確。

## 版面設定

輸入 `/desktop-statusline`，或點狀態列最右邊的 `⚙`，會打開設定畫面。上方是即時預覽，下方分兩層：

1. **所有行**：列出每一行和它的欄位。可以「編輯第 N 行」、用 `↑` `↓` 調整行的順序、刪除一行、「+ 新增一行」（最多 4 行），或「恢復預設」（全部欄位排成一行）。
2. **編輯一行**：列出這一行的欄位，可以「往前」「往後」調整順序、「移到上一行 / 下一行」或「移除」。下方「新增欄位」只會列出還沒放到狀態列上的欄位，點一下就加到這一行的最後面，所以不會打錯字，也不會重複。

在終端機裡按 `ctrl+x` 再按 `tab` 可以把焦點移到設定畫面，用 `tab` 移動、`enter` 選擇，`esc` 關閉。版面會存在 mod 自己的 store，所有 session 共用。

## 其他設定

| 選項 | 預設 | 說明 |
| --- | --- | --- |
| `display` | `both` | 百分比類欄位怎麼顯示：`both` 進度條加百分比、`bar` 只有進度條、`percent` 只有百分比文字 |
| `percent` | `used` | `used` 顯示已用多少；`remaining` 改成顯示剩下多少（`剩 66%`），進度條也會隨用量減少 |
| `barWidth` | `10` | 進度條的寬度（字元格數，3 到 40） |
| `showInTerminal` | `false` | 也在終端機的輸入框上方顯示 |

`display` 和 `percent` 在 `/config` 裡是下拉選單，也可以寫進 `~/.claude/settings.json`：

```json
{
  "pluginConfigs": {
    "desktop-statusline": {
      "options": { "display": "bar", "percent": "remaining" }
    }
  }
}
```

沒有資料的欄位會自動隱藏，例如使用 API key 時的 5 小時和 7 天用量；整行都沒有資料時，那一行也不會顯示。
